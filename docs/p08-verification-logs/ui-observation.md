访问等级键盘选择、公司下拉点击和窗口公开Raise都曾返回USER_CONTROL_ACTIVE；部分调用伴随CELL_CANCELLED/state_reset及uncertain动作回执。每次先观察实际状态，未重放原批次。公司菜单曾被读到虚构公司选项，但后来实际仍“请选择公司”，不能将菜单打开或键盘派发当选中成功。随后停止GUI，未请求用户重复代做。
