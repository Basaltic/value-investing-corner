## 隔离夹具与读取验证

使用Rust测试模块的显式ignored函数 `build_isolated_gui_fixture`，经同一原生create_company/save_fact/define/observe业务函数创建：

- 1家 P06财务验收公司（虚构），非上市；
- 4条财务事实：2023年度营收100、2024年度营收null/待核、2025年度营收140、2025年度营业成本84。均CNY/元/CAS/同合并报表口径；
- 1个文本定义及1条文本观测，正文明确“这是测试公司，不是真实研究结论”；
- 1个数值客户定义（人/期末客户，非金额币种空）及2023为10、2024为null待核、2025为14三条观测。

夹具必须明确传入隔离库路径，并断言路径尾名为 `com.valueinvestingcorner.p06validation/research.sqlite3`、库内公司列表为空，遇既有公司即失败，不覆盖、不重复创建。此次显式运行通过，日志 `fixture-tests.log`。它证明原生业务写入，不证明前端表单录入。

重进公司页实际读到1家虚构公司；公司详情→手工财务与指标观测入口可用。AX确认原生财务页面不是白屏：表单、指标选择、日期范围、审核复选框及读数列表均出现。

默认未勾待核：营收列表按2023/2024/2025显示100/缺值/140；原始事实读取显示4条链、1条待核，待核事实未出现在默认事实清单。固定毛利率显示2025年40%，其它缺少输入项显示未展示；文本观测正文卡片与客户数10人/14人出现。图表只有role=image的容器可从AX读到，不能证明canvas实际绘制或断点/灰点视觉正确。
