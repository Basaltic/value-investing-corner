# P04 本地公司资料库合同

## 使用入口与范围

在原生桌面窗口中进入「公司研究 → 公司档案 → 打开公司资料库」。提供手动文件、来源链接、文本笔记的添加、编辑、标签搜索、归档和恢复在用。公司、资料各有独立ID，挂接真实SQLite；无浏览器假数据、无AI、无正式判断历史、无财务指标、无自动采集、无全文搜索引擎或云同步。

资料笔记为可编辑正文，不等同P05的正式判断版本；P04不承诺评论自动保存、版本差异或不可变历史。保存采用手动操作，错误或取消选择时保留表单输入（页面内）；关闭或离开页面未保存内容不持久化。

## 本地文件

- 保存文件时Rust打开原生单文件选择框，前端不提供任意源路径。
- 内部复制（推荐）：以资料UUID与安全扩展名存入应用数据目录 `attachments`；原件改名、移动不影响复制件。复制件和SQLite均进入基本备份。
- 外部引用：存原始文件的规范绝对位置，不复制原件；备份只含记录，不含外部文件。失效明确显示 missing，可经原生选择框重新定位同内容文件（SHA-256相同）；内容不同须新增资料。
- 内容hash发生变化时标 changed，拒绝静默把新内容当原資料预览。复制件路径限定资料ID与扩展名，拒绝越界、目录或符号链接。文件导入上限50 MiB，内嵌预览上限20 MiB；文本正文上限1 MB UTF-8字节。
- 未支持格式保留元数据和「在访达显示文件」入口；不自动执行、调用shell打开或运行导入文件。来源链接只允许不含凭据的HTTP/HTTPS，显式按钮交系统浏览器打开，不抓取页面。
- 资料归档不删除记录或复制件；当前不做永久删除、文件替换或去重合并。

## 预览与CSV

- TXT只显示原文本；Markdown通过react-markdown安全渲染，跳过原始HTML，不自动加载外链图片或打开正文内链接。
- 支持PNG/JPEG/GIF/WebP，扩展名与文件头一致后给本地Blob；图片解码由WebView完成。其他图片格式不强行解析。
- PDF通过锁定的PDF.js 4.10.38本地渲染及分页，标准字体与CMap随应用打包，无外部CDN；关闭eval，受密码保护/损坏报错，无OCR。文字提取仅供本页复制，不等同全文检索。
- 文本/CSV支持UTF-8（可含BOM）；其它编码明确报错，不猜编码。CSV采用csv解析器，首行表头、逗号分隔，不忽略字段数不一致；最多100列，预览前100数据行，计算总数据行数。保留前导零、空值、引号、换行与文本值，不求值、不运行公式。
- CSV导入先存原件资料；用户为实际列填写映射名称，可留空忽略，至少一列、非空名称唯一，确认后存SQLite。这里的结构化资料是“原件＋可复算解析＋已确认映射”，不写FinancialFact或MetricObservation，不偷跑P06。

## 原生窄命令与权限

`material_create/list/get/update/archive/preview/csv_mapping/import_file/relocate/reveal/open_source` 使用管理的StorageStatus；前端只传公司或资料ID、正文/标签、模式/映射，不传数据库位置或SQL。文件选择取消返回null，未新增条目。

只有dialog插件在应用注册，使用Rust接口；dialog/fs/opener的通用前端权限未开放，capabilities仍core:default。opener作为Rust库只提供已登记资料的reveal与来源URL打开；不注册通用opener命令。dialog传递依赖fs不等同授予前端fs能力。

CSP新增本地blob图片/worker/字体及同源connect读取打包字体，仍无远程HTTP源、unsafe-eval或任意文件asset协议，object-src仍none。Web和共享包未改。
