# P04 原生界面观察记录

## 环境与范围

macOS ARM64；独立 debug 验收应用（与正式应用数据隔离）。本轮只验证本地资料库，不含 AI、正式判断、财务指标或自动采集。原生进程重启后重新观察，不复用旧进程或 AX 索引。

## 已观察的核心路径

1. 从工作台进入公司研究，创建「P04资料验收公司（虚构）」；公司详情存在「打开公司资料库」入口。
2. 资料库空态与三类入口可见；使用真实键入创建「P04本地笔记（虚构）」，正文为 Markdown，标签「护城河, 财报」。保存后资料数从 0 到 1。
3. 选择「本地文件」，填写「P04虚构PDF资料」，默认内部复制；点击保存打开原生单文件选择框，表单显示保存中并禁用。
4. 两次路径定位快捷键未改变选择框状态。没有将工具成功返回当作选择成功。通过用户接管工具由用户选中虚构 sample.pdf 并交回后，实际观察资料数为 2，文件元数据为内部复制、sample.pdf、2355 bytes。
5. 首次 PDF 只画出边框、页码 1/2 可见但没有文字；点击下一页页码变为 2/2，文字仍缺失。此为实际发现的缺陷，不算通过。
6. 补入锁定 PDF.js 包自带标准字体与字符映射，本地同源加载；允许本地字体和 worker，未开放远程网络。重新打包并退出重启独立验收应用。
7. 重启后同一公司与两条资料均保留。再次打开同一份 PDF，第一页显示「P04 fictional research fixture - Page 1」与「Local PDF page 1: content preserved.」，点击下一页显示 2/2 与 Page 2，末页下一页禁用。修复后的文字与翻页已目视确认。
8. 查看笔记，Markdown 一级标题「虚构验收笔记」与正文「仅验证本地保存与预览，不是真实公司判断。」正常；两标签仍在。
9. 归档笔记后在用数为 1；切到已归档显示该笔记与「恢复在用」。恢复后已归档清单为空。
