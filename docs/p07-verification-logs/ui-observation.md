1. 打开独立应用，工作台返回“原生连接正常”，侧栏“指标看板”入口可用，能力说明包含看板。
2. 初次看板读取：配置v1，关注组含1家虚构公司，模板顺序待读→指标→待补→最近正式判断。指标营收2023/2024/2025显示100/缺值/140，文本正式v1正确；资料为待处理，待补内容明确本人/夹具输入，不自动生成推荐。
3. 点击编辑看板：组名称/公司分组选项、添加四模板、卡片显隐/排序、所选指标及日期/待核配置控件出现。
4. 点击营收卡“上移卡片”，原生AX序列实际变为指标在待读前，状态显示未保存；点击待读“显示卡片”取消，再保存，配置v2，正常视图不显示待读卡。
5. 点击重新载入：配置v2/指标在首位/待读隐藏保持；实际截图可见页面正常渲染，样式沿用项目暖纸/绿主题。滚动取得趋势及列表实际画面：2024缺值处没有跨点连线，2023/2025点与100/140表格对应；不以AX image容器当渲染证据。
6. 编辑，输入“需要补证”并添加组，组标题及空态出现。指标菜单打开，但菜单项指针点击返回MENU_OWNERSHIP_UNVERIFIED / not_dispatched，未选择成功，后续动作未执行。单独读当前AX确认菜单仍打开；Escape关闭。未重复点击失败目标。
7. 公司分组菜单公开显示未分组/关注/需要补证，当前“关注”。通过当前菜单Down+Return实际选中“需要补证”，公司移到该组、原关注显示空态，AX分组值对应。
8. 勾回待读卡显示并切换待核，保存得到配置v3；数值列表新增待核列，缺值仍显示缺值而非0。
9. 原生勾待读条目“已完成”后AX完成值1、无未完成待读空态；输入“核对虚构公司复购指标”并添加，待补列表实际多出该项，输入清空。
