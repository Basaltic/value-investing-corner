本轮测试使用 debug 构建时的独立 identifier `com.valueinvestingcorner.p03validation`，正式 `tauri.conf.json` 未改；仅在验收数据目录创建虚构公司，不在正式研究库建立样例。

## 原生观察

- 按实际 `.app` 路径读取窗口，用户正在操作时立即暂停并通过接管工具请求交回控制；交回后重新观察。
- 原生工作台实际显示“价投小角落 · 0.1.0 · 原生连接正常”。
- 导航“公司研究”进入空列表与创建表单；字段与焦点可读。
- 初次 AX `set_value` 对 React 表单未产生提交值，必填校验阻止空名称；改用显式点击 + 键入后成功保存。
- 验收虚构名称为“P03验收样例公司（虚构）中国”；第一次键入注册地时文本落在名称中，未将此误当注册地验证通过。
- 同名再次提交后显示重复原因和已有档案入口，表单禁用、尚未写入。
- 点击“确认仍然保存”后列表从 1 变为 2，两个独立档案，不合并。
- 打开第二公司详情，分别添加 A股代码 600001（SSE）、600002（交易所空），详情显示两条独立证券。
- 证券市场下拉辅助控制/向下键未切换选项，故原生跨市场/ADR选择未实证；Rust 测试覆盖 HK / US / ADR 存储。
- 退出应用并重新打开（新进程），公司列表仍为 2；搜索证券代码 600002 后返回一个档案并显示两条证券，证明原生持久化与代码搜索。
- 所有窗口截图仅为工具即时观察，未另存图片。
